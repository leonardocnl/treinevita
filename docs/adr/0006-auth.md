# ADR 0006: Sign in with Google, built in-house

## Status

Accepted, 2026-11-07. Implementation in phase 1.

## Decision

- Google OAuth implemented without an auth library (same approach as the author's other projects), with PKCE and `state`.
- Server-side sessions; only a hash of the session token is stored. Cookie `HttpOnly`, `Secure`, `SameSite=Lax`.
- Access restricted by `ALLOWED_EMAILS` in the MVP. Opening to the public changes this rule, not the architecture.
- Identities (provider + subject) are separate from users, so other providers or company SSO can be added later.
